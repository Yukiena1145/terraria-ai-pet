# 泰拉瑞亚 AI 桌宠（Coopanion 世界插件）· 未完成版

> 一个 17 岁高中生，在高考前挤时间写出来的泰拉瑞亚 AI 桌宠项目。
> 它现在还很笨、很好笑，但真的能自己砍树、挖矿、开背包、合成、放方块、刷墙、打怪。

## 这是什么？

这是一个 **Coopanion（CoO）桌面宠物的「世界（World）插件」**，扩展 ID 是 `cortico-world-terraria`。

装上之后，你的桌宠可以「进入」官方泰拉瑞亚 1.4.4：

- 桌宠的**大模型当大脑**，负责理解你的话、做计划、选动作；
- 这个插件负责把游戏「翻译」成桌宠能用的 **26 个原子动作**（看状态、走路、挖矿、放方块、打怪……）；
- 本机的 Python 服务负责「眼睛和手」：只读游戏内存 + 模拟键盘鼠标；
- 不修改任何游戏文件，不是外挂，是单机自娱自乐的学习项目。

## 为什么是桌宠插件，而不是独立程序？

最初我想做一个**独立的 AI Agent**：自带大模型规划、对话、记忆，自己就能玩。

但做出来效果不理想：

- 独立程序要自己维护一整套「大脑」（对话、人设、记忆、语音），工作量巨大；
- 还要和玩家抢输入、抢窗口焦点，体验很差；
- 自己写的小模型规划经常「想一出是一出」。

后来发现 **CoO 桌宠本身就有大模型、人格、语音和 UI**，于是我换了个思路：

> **让 CoO 当大脑，这个项目当眼睛和手。**

桌宠用她/他自己的模型来思考和说话，Python 服务只负责「看游戏」和「动键鼠」。这样稳定得多，也更好玩——你是在和自己的桌宠一起打泰拉瑞亚，而不是在用一个冷冰冰的脚本。

## 架构

```
┌────────────────┐   26 个原子动作（工具调用）   ┌──────────────────────┐
│ Coopanion 桌宠  │ ───────────────────────────→ │ cortico-world-       │
│ （大模型 = 大脑）│ ←─────────────────────────── │ terraria 世界插件     │
└────────────────┘   状态 / 回执 / 失败截图      └──────────┬───────────┘
                                                           │ HTTP
                                                ┌──────────▼───────────┐
                                                │ Python 服务 :5000     │
                                                │ ├ skills.py 技能层    │
                                                │ ├ executor.py 执行层  │
                                                │ └ monitor.py  记忆层  │
                                                └──────────┬───────────┘
                                                           │ 只读内存 / SendInput
                                                ┌──────────▼───────────┐
                                                │ 官方 Terraria 1.4.4   │
                                                └──────────────────────┘
```

- **ClrMD bridge（32 位）**：每 50ms 读一次玩家坐标、血量、背包、31×31 地形、敌人列表；
- **pydirectinput**：模拟键盘鼠标（要求游戏在前台）；
- **26 个原子动作**：看 / 走 / 跳 / 跳上方块 / 砍树 / 挖矿（可指定格）/ 开关背包 / 查快捷栏 / 查背包 / 找物品 / 搬格子 / 选格子 / 合成（可长按批量）/ 放置 / 搭柱子 / 搭方框 / 按蓝图施工 / 放墙 / 批量放墙 / 房屋检查 / 战斗 / 持续开火 / 停止 / 查物品 / 启动游戏；
- **原生控制面板**：地图、血量、背包、日志、快捷按钮、**蓝图编辑器**（点格子画图，保存后桌宠照着造）。

## 现在能做什么（实测过）

- 看状态、31×31 地图、150 格内的敌人（带格坐标/距离/血量）
- 走路、跳跃、跳上方块（1 格台阶会自动走上去）
- 砍树、挖矿（可以指定挖面前那一格）、开/关背包
- 查快捷栏/背包、找物品、搬格子、选格子
- 合成（长按连续制作，一次做几十上百个木墙）
- 放方块（自动找支撑、拒绝放在自己身上）、搭柱子、搭方框、按蓝图施工
- 放背景墙（需要锚点）、批量刷墙、房屋合法性检查
- 战斗（追着砍）、矿车持续开火（锁怪 + 长按左键、30ms 贴准星）
- 动作失败自动截图（开发阶段功能，方便排查是程序错还是「不会玩」）

## 还没做好的（老实说）

- **造房子还是容易翻车**：站立位置、被自己身体挡住、跳跃精度都不稳定；
- **6 格高的柱子跳不上去**（已加「垫脚台阶」兜底，但仍不完美）；
- **矿车战高速移动时瞄准有延迟**，怪在屏幕外时只能把鼠标贴在窗口边缘；
- 内存偏移基于 1.4.4，**游戏一更新就会失效**；
- 只支持 **Windows + 官方 1.4.4**，联机和模组都没测试；
- 界面和提示以中文为主，英文翻译不完整；
- 代码是一个高中生挤时间写的，结构和注释比较「野生」，欢迎重构。

## 快速开始

完整步骤见 [docs/SETUP.md](docs/SETUP.md)，简单说：

1. 安装 Python 3.10+，`pip install -r requirements.txt`；
2. 用 `bridge/build_bridge.bat` 编译 32 位内存读取器（需要 .NET Framework 4.8）；
3. 复制 `config.example.json` 为 `config.json`，填好游戏路径/窗口标题（DeepSeek key 可留空）；
4. 运行 `python main.py`，确认 `http://127.0.0.1:5000/api/health` 返回 ok；
5. 把 `coopanion-extension/` 放进 CoO 的扩展目录，并在扩展的 `package.json` 里 link 它；
6. 打开 CoO 设置 → 泰拉瑞亚世界 → 启用，面板地址填 `http://127.0.0.1:5000`；
7. 进游戏世界，让桌宠先 `terraria_see` 看一眼，再让她/他干活。

## 配置

- `config.json`（从 `config.example.json` 复制）：
  - `deepseek_api_key`：**插件模式下可以留空**（规划交给 CoO 的模型）；只有网页面板的旧「关键词/本地 LLM」模式需要；
  - `window_title` / `exe_path`：游戏窗口标题和 Terraria.exe 路径；
  - `enemy_range_tiles`：找怪范围，默认 150 格；
  - `dev_screenshot_on_failure`：失败自动截图，正式使用时可以关掉。
- 插件配置（CoO 设置里）：
  - `worlds.terraria.panelUrl`：本机服务地址，默认 `http://127.0.0.1:5000`；
  - `pythonExe` / `projectDir`：Python 解释器和项目目录；
  - `autoStart`：服务没起来时自动拉起；
  - `inventoryKey`：背包键，默认 `escape`；
  - `showMap` / `maxStatusChars`：面板显示相关。
